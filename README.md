# Hisaab Kitaab (voice khata app)

## APK banane ke steps
1. GitHub par naya repository banao.
2. Is folder ki saari files repo mein upload karo. `.github` folder zaroor jaye. Agar woh upload na ho to "Add file > Create new file" mein naam likho `.github/workflows/build-apk.yml` aur file ka content paste karo.
3. Repo ke "Actions" tab mein "Build APK" kholo, "Run workflow" dabao (ya upload par khud chalta hai).
4. 5 se 10 minute baad run kholo. Neeche "Artifacts" mein HisaabKitaab-apk download karo.
5. Zip kholo, andar app-debug.apk hai. Phone mein install karo (Unknown sources allow karna padega).

## Pehli baar
App mic ki permission maangegi, "Allow" karo. Phone mein Google (speech) service aur internet chahiye.
